# OZ Fashion House website

## What I’ll build
- Replace the blank page with a polished, mobile-friendly bridal storefront.
- Use the supplied OZ Fashion House logo as the visual anchor and browser icon.
- Present Bride, Groom, Bridesmaids, and Men’s & Ladies’ Accessories as clear shopping categories.
- Add direct WhatsApp calls to action using 0701090109 and show the Namugongo, Wakiso, Uganda location.
- Include a concise services section and footer so customers can quickly understand the business and make an enquiry.

## Visual direction
- Luxury editorial styling inspired by the supplied mark: deep black, champagne gold, warm ivory, and subtle metallic details.
- Elegant serif display type paired with a clean, readable sans serif.
- Strong photography-led first impression, restrained motion, crisp dividers, and refined spacing.

## Technical details
- Build the page in the existing TanStack app with responsive Tailwind styling and semantic design tokens.
- Store the uploaded logo through the project asset system; create a lightweight favicon from the same mark.
- Add page-specific title, description, social metadata, semantic headings, and image alt text.
- Verify the final page visually on desktop and mobile and check the current build status.
